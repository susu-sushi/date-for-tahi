# Date For Tahi ❤️

A cute single-page surprise date website for GitHub Pages.

## Add photos
Replace the placeholder `.photo` blocks in `index.html` with `<img>` elements, or ask ChatGPT to customize them after choosing your photos.

## Add music
Place your legally obtained/licensed `music.mp3` file beside `index.html`. The browser will not autoplay it; Tahi can tap the Music button.

## GitHub Pages
Create a repository, upload `index.html` (and `music.mp3` if you have permission to use the recording), then enable Settings → Pages → Deploy from branch → main → root.
